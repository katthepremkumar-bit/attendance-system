# Attendly - Student Attendance System

A student attendance management system built using React, Vite, and Supabase.

## Features
- Google sign-in
- Student attendance management
- Admin dashboard

## Setup
1. Install dependencies using `npm install`.
2. Create a `.env` file using `.env.example` as a guide.
3. Add your Supabase configuration to `.env`.
4. Start the development server using `npm run dev`.
